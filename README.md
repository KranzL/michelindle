# michelindle

Daily fine dining puzzle. Guess the signature dishes of two-star and three-star Michelin restaurants.

Play at [lkranz.com/michelindle](https://lkranz.com/michelindle).

## How it works

Every day the kitchen serves three courses: three real starred restaurants, from iconic to deep cut. Name each one's signature dish.

- **prix fixe** -- the restaurant is shown; choose its dish from four plates. Three clues, three guesses.
- **a la carte** -- the restaurant is hidden; search the full carte and call both the dish and the house. Six clues, six guesses, with country / course / stars feedback on every miss.

Mode locks when the first course begins. New service nightly at midnight EST.

## Stack

Static HTML + vanilla JS. No backend, no build step. Restaurant bank and daily schedule live in plain JS files.
